# 上传实操指南：4 小时角色语音合集传到 B 站 / YouTube

> 面向「已经跑完 `python -m voicepack all`」的你。命令都在项目根目录执行，路径按需替换。
> 本文只讲**过审和上传**，工具怎么装、参数含义见 [README](../README.md)。

## 0. 三条铁律

1. **先听完证据，再上传。** 工具会把所有 `drop`+`review` 句拼成 `<名字>_suspect.mp3`，配套 `.csv` 有每句的 `start,end`；这是你唯一能低成本把"漏网"听出来的机会。
2. **封面和画面也要过审。** 用**全年龄** CG，不要用 R18 图、擦边图；标题/封面是第一道机审。
3. **二次创作、非商业。** 语音版权属于 ゆずソフト（柚子社）。不开创作激励、不接广告、不卖资源；标注来源，被要求下架就下架。

## 1. 过审前自检（5~10 分钟）

```bat
:: ① 对着时间轴听疑似清单（qa_check 会校验 csv 和 mp3 是同一次生成的）
python tools\qa_check.py "E:\mrxyy\voicepack_out"
:: ② 听到确实该删的：在 filter_report_verified.csv 里，把该行 action 改成 drop
::    （没有 verified 就改 filter_report.csv；Excel 打开不乱码，改完保存为 csv）
:: ③ 重出主产物（命中转写缓存，不重新转写；通常 5~10 分钟）
python -m voicepack build "E:\mrxyy" --image "D:\cg\noz.png" --title "四季 ナツ"
```

- 只改 `action` 列，`keep`/`drop`/`review` 三档，别留空、别新增列；不要另存成 `.xlsx`。
- `build` 会自动优先读取 `filter_report_verified.csv`；若你把清单另存成了 `my_list.csv`，用 `--decisions my_list.csv` 指定。
- 想快速复查改完后的疑似清单（不重合成主音轨）：`python -m voicepack suspect "E:\mrxyy"`。
- 拿不准就整段砍：`--drop-scenes 12,15`（场景号见 `filter_summary_verified.txt`）。第一次传强烈建议 `--strict` 或上面的人工复核，别赌。

## 2. 分段策略（4 小时单 P 不建议）

B 站单视频 4 小时：转码慢、审核排队久、一旦违规整条全没。建议按 20 分钟切：

```bat
python -m voicepack build "E:\mrxyy" --image "D:\cg\noz.png" --title "四季 ナツ" --split-minutes 20
```

- 产物：`<名字>_part_01.mp4/.mp3`、`_part_02`…（4 小时约 12 个 P），画质参数不变。
- 上传：B 站「投稿 → 上传视频」一次选多个文件，会自动成为**分 P**；再在稿件管理里「加入合集」，
  合集命名如「四季ナツ 语音合集」；YouTube 用同名分 P 或独立播放列表。
- 命名模板：`{角色名} 01`、`{角色名} 02`…（例：`四季ナツ 01`、`四季ナツ 02`），
  标题不要带 P 号以外的解释，合集名保持「角色名 + 语音合集」。
- **封面统一**：所有 P 用同一张 `cover.png`（或同一角色同一风格），合集看起来才像一套；不要每 P 换擦边图。
- 切点会落在句子之间（每 P 时长可能略差几秒属正常），qa_check 会逐段检查每片是否可解码。

## 3. 标题 / 简介 / 标签怎么写不触发审核

**标题**（避免「解包、提取、破解、全语音、R18、成人」这类词；用「二次创作 / 整理」口径）：

> 例：`【Galgame/二次创作】四季ナツ 语音合集｜千恋＊万花`

**简介模板**（复制改角色名即可）：

```text
【作品】《千恋＊万花》角色语音整理（同人二次创作）
【角色】四季ナツ
【内容】游戏内角色语音按场景整理，已按平台规范清理不适宜内容
【声明】素材版权归 ゆずソフト（Yuzusoft）所有；本视频为个人收藏/同人分享，非商业用途，未开启收益
【说明】如有侵权请告知，会立即下架
```

**标签**（≤10 个，别堆敏感词）：`千恋万花` `四季ナツ` `柚子社` `ゆずソフト` `galgame`
`角色语音` `二次创作` `游戏配音` `语音合集`

**封面**：直接用工具生成的 `cover.png`（1920×1080）即可；B 站建议 16:9、≥1146×717。
不要用带暗示性的 CG 作封面——封面被驳回是最常见的第一次失败。

## 4. 版权风险与自保

- **风险来源**：语音/立绘/剧本版权（ゆずソフト）；B 站「版权投诉 → 稿件下架/扣分」，YouTube「版权方申明 → 限流/下架/停用收益」。
- **做法**：简介明确写素材来源与二创性质；不商用、不开激励、不设付费；不打包"资源下载"；
  收到侵权通知**先下架再沟通**，别硬扛。
- **降低概率**：单 P 20 分钟、封面全年龄、标题不擦边；不要用游戏 BGM（音乐最容易被 Content ID 命中），
  本工具产物只有人声+静音，相对安全。
- **心理预期**：这类内容属于灰色二创，平台随时可能清理；把它当"个人收藏的公开备份"，别当正经营业内容。

## 5. 常见驳回原因 & 申诉话术

| 驳回原因 | 处理 |
| --- | --- |
| 低俗/色情（音频里有喘息、呻吟） | 按 §1 把对应句改 `drop` 重出；申诉前先删减 |
| 封面/标题擦边 | 换全年龄图、改标题重投 |
| 版权（音乐/画面/内容） | 删 BGM、换全年龄 CG；确认二创口径 |
| 疑似搬运/无意义内容 | 简介写清整理方式与角色信息，分 P 标题写具体内容 |
| 时长/文件过大转码失败 | 用 `--split-minutes 20` 重投 |

**申诉模板**（短、只讲事实）：

> 您好，本视频为《千恋＊万花》角色语音的**同人整理**，非商业用途、未开启收益，简介已标注素材版权归属。
> 已按平台规范自行清理不适宜内容（共剔除 N 句，留档可提供）。如有具体违规时间点，请告知，我会立即删除对应片段并重新投稿。

## 6. 敏感片段留档（被要求下架时能快速裁剪）

上传前把这三样**另存一份**到别的盘（别只留在 `voicepack_out`）：

1. `filter_report_verified.csv`（含全部 `drop` 记录，`name` 能对上原始 ogg 文件名）；
2. `<名字>_suspect.csv` + `<名字>_suspect.mp3`（你人工听过的那一版证据）；
3. `filter_summary_verified.txt`（按场景统计，方便定位整场）。

被平台点名某个时间段时：按时间轴在 csv 里找到 `name`，在 `filter_report_verified.csv` 把对应行改 `drop`，
然后 `python -m voicepack build … --decisions filter_report_verified.csv` 重出删减版即可（不重转写）。
